Parte 2 — Exercícios Práticos

Exercício 1 — Calculadora de Desconto

Crie as variáveis preco (valor: 200) e desconto (valor: 30).
Calcule o precoFinal subtraindo o desconto do preço.
Depois use console.log para mostrar:
— o preço original
— o desconto
— o preço final 

let preco = 200;
let desconto = 30;
let precoFinal = preco - desconto;

console.log(preco);
console.log(desconto);
console.log(precoFinal);
Exercício 2 — Classificador de Idade

Crie uma variável idade com qualquer número.
Usando if / else if / else, imprima no console:
— "Criança" se idade for menor que 12
— "Adolescente" se idade for entre 12 e 17
— "Adulto" se idade for 18 ou mais

Teste com pelo menos 3 idades diferentes. 

let idade = 8;
if (idade < 12) {
  console.log("Criança");
} else if (idade < 18) {
  console.log("Adolescente");
} else {
  console.log("Adulto");
}

// Teste com outras idades:
idade = 15;
if (idade < 12) {
  console.log("Criança");
} else if (idade < 18) {
  console.log("Adolescente");
} else {
  console.log("Adulto");
}
