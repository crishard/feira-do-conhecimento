O que é uma Engine 3D?

🧠 Conceito: O que é uma Engine?

Uma engine de jogos (motor de jogo) é um conjunto de ferramentas e código que facilita a criação de jogos. Em vez de você programar tudo do zero — como desenhar triângulos na tela, calcular sombras e detectar colisões — a engine já faz isso por você.

💡 Exemplos famosos: Unity, Unreal Engine, Godot.
No nosso curso usaremos o Three.js, que roda direto no navegador!

O Three.js é uma biblioteca JavaScript que usa o WebGL (tecnologia do navegador) para renderizar gráficos 3D. Você escreve código JavaScript e ele cuida de todo o trabalho pesado com a placa de vídeo.

🏗️ Os 3 Pilares de uma Cena 3D

Todo jogo 3D precisa de três coisas fundamentais:

1. Cena (Scene) — O "mundo" onde tudo existe. Você adiciona objetos, luzes e câmeras aqui.

2. Câmera (Camera) — O "olho" do jogador. Define de onde e como o mundo é visto.

3. Renderizador (Renderer) — O "pintor". Pega a cena + câmera e desenha tudo na tela.

💻 Seu Primeiro Código

Veja como criar uma cena com um cubo roxo — exatamente o que está sendo exibido ao lado:

// 1. Importar o Three.js (via CDN — sem instalar nada)
// <script src="https://cdn.jsdelivr.net/npm/three@0.160/build/three.min.js"></script>

// 2. Criar a CENA (o mundo)
const cena = new THREE.Scene();

// 3. Criar a CÂMERA
//    PerspectiveCamera(fov, aspecto, near, far)
//    fov = campo de visão (75° = visão ampla)
const camera = new THREE.PerspectiveCamera(
  75,                              // campo de visão
  window.innerWidth / window.innerHeight, // proporção da tela
  0.1,                             // distância mínima de renderização
  1000                             // distância máxima de renderização
);

// Posicionar a câmera para trás e para cima
camera.position.set(0, 2, 5);

// 4. Criar o RENDERIZADOR
const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.setSize(window.innerWidth, window.innerHeight);
document.body.appendChild(renderer.domElement); // adiciona ao HTML

// 5. Criar um CUBO
//    BoxGeometry(largura, altura, profundidade)
const geometria = new THREE.BoxGeometry(1, 1, 1);
const material  = new THREE.MeshStandardMaterial({ color: '#7c3aed' });
const cubo = new THREE.Mesh(geometria, material);

// 6. Adicionar o cubo à cena
cena.add(cubo);

// 7. Adicionar LUZ (sem luz, nada aparece)
const luz = new THREE.DirectionalLight('#ffffff', 1);
luz.position.set(5, 10, 5);
cena.add(luz);
cena.add(new THREE.AmbientLight('#ffffff', 0.3));

// 8. Renderizar a cena (desenhar 1 vez)
renderer.render(cena, camera);

🔍 Entendendo cada parte

Geometry é a forma do objeto — define os pontos e triângulos no espaço 3D. BoxGeometry(1,1,1) cria um cubo de 1x1x1 unidades.

Material define a aparência visual — cor, brilho, textura. MeshStandardMaterial responde à luz de forma realista.

Mesh combina geometria + material para criar um objeto visível na cena.

🎯 Regra de ouro: sem luz na cena, todos os objetos aparecem pretos com MeshStandardMaterial. Sempre adicione pelo menos uma AmbientLight!

✏️ Experimente

O cubo ao lado está rodando com o código exato acima. Tente mentalmente mudar:

• A cor '#7c3aed' para '#ff0000' (vermelho)

• O BoxGeometry(1,1,1) para BoxGeometry(2,1,0.5) (retangular)

• A posição da câmera de (0,2,5) para (0,5,8) (mais longe)
