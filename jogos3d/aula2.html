🎨 Materiais — A Aparência dos Objetos

O material determina como o objeto parece. Diferentes materiais reagem à luz de formas diferentes:

MeshBasicMaterial — Sem reação à luz. Sempre aparece com a cor pura. Útil para HUDs e ícones.

MeshStandardMaterial — Física baseada (PBR). Reage à luz de forma realista. Use na maioria dos casos.

MeshPhongMaterial — Mais leve que o Standard. Bom brilho especular (reflexo de luz).

MeshWireframeGeometry — Mostra só as arestas (wireframe). Ótimo para debug. 
// Material básico — não precisa de luz
const matBasico = new THREE.MeshBasicMaterial({
  color: '#ff6600',
  wireframe: false // true = mostra só arestas
});

// Material realista — precisa de luz na cena
const matRealistico = new THREE.MeshStandardMaterial({
  color: '#7c3aed',
  roughness: 0.3,  // 0 = espelho, 1 = fosco
  metalness: 0.8   // 0 = plástico, 1 = metal
});

💡 Luzes — Iluminando o Mundo

Sem luz, objetos com MeshStandardMaterial aparecem completamente pretos. Existem vários tipos de luz:

Tipo de LuzComportamento
AmbientLightIlumina tudo igualmente, sem direção. Sem sombra.
DirectionalLightComo o sol — raios paralelos, projeta sombras.
PointLightComo uma lâmpada — irradia em todas as direções.
SpotLightComo um holofote — cone de luz direcionável.
// Luz ambiente (iluminação base)
const ambiente = new THREE.AmbientLight('#ffffff', 0.4);
cena.add(ambiente);

// Luz direcional (como o sol)
const sol = new THREE.DirectionalLight('#fffbe6', 1.2);
sol.position.set(10, 20, 10);
cena.add(sol);

// Luz pontual (como uma lâmpada)
const lampada = new THREE.PointLight('#60a5fa', 2, 20);
lampada.position.set(0, 3, 0);
cena.add(lampada);

📐 Posicionando Objetos no Espaço 3D

No espaço 3D, cada objeto tem uma posição nos eixos X, Y e Z:

X → Esquerda (-) e Direita (+)
Y → Baixo (-) e Cima (+)
Z → Para longe (-) e Para perto (+) 
// Posicionamento
objeto.position.set(2, 0, -3); // x=2, y=0, z=-3

// Rotação (em radianos — não graus!)
objeto.rotation.y = Math.PI / 4; // 45 graus

// Escala
objeto.scale.set(2, 0.5, 1); // 2x largo, 0.5x alto, normal no z
