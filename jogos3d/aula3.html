Animação e o Game Loop

🔄 O que é o Game Loop?

Todo jogo roda em um loop infinito. A cada iteração do loop, o jogo:

1. Lê entradas — teclado, mouse, controle
2. Atualiza o mundo — move objetos, calcula física, verifica colisões
3. Renderiza o frame — desenha tudo na tela
4. Repete — normalmente 60 vezes por segundo (60 FPS)

No navegador, usamos requestAnimationFrame — uma função nativa que chama seu código antes de cada redesenho da tela, sincronizado com o monitor (geralmente 60fps).

💻 O Loop Básico

// Estrutura básica de todo jogo em Three.js

function gameLoop() {
  // Agenda a PRÓXIMA chamada antes de fazer qualquer coisa
  requestAnimationFrame(gameLoop);

  // ① Atualizar o mundo
  cubo.rotation.y += 0.01; // gira um pouco a cada frame

  // ② Renderizar (desenhar) o frame atual
  renderer.render(cena, camera);
}

// Iniciar o loop (chama uma vez; depois se auto-chama)
gameLoop();
⚠️ Cuidado com velocidade independente de FPS!
Se você adiciona 0.01 por frame e o jogo roda a 30fps em vez de 60fps, o objeto se move na metade da velocidade. A solução é usar delta time!

⏱️ Delta Time — A Solução Certa

O delta time é o tempo passado desde o último frame. Multiplicando o movimento por ele, a velocidade fica consistente em qualquer FPS:

const clock = new THREE.Clock(); // relógio do Three.js

function gameLoop() {
  requestAnimationFrame(gameLoop);

  const delta = clock.getDelta(); // segundos desde último frame
  // ex: 0.016 em 60fps, 0.033 em 30fps

  // Velocidade em unidades POR SEGUNDO (não por frame)
  cubo.rotation.y += 1.0 * delta; // 1 radiano/segundo sempre
  cubo.position.x = Math.sin(clock.getElapsedTime()) * 3;

  renderer.render(cena, camera);
}
gameLoop();

📐 Funções Matemáticas Úteis

Para criar animações suaves e naturais, as funções seno e cosseno são suas melhores amigas:

const t = clock.getElapsedTime(); // tempo total em segundos

// Oscila de -1 a +1 suavemente
objeto.position.y = Math.sin(t) * 2;

// Também oscila, mas defasado
objeto.position.x = Math.cos(t) * 3;

// Combinando: movimento circular!
objeto.position.x = Math.cos(t) * 3;
objeto.position.z = Math.sin(t) * 3;

O demo ao lado mostra esferas se movendo com seno/cosseno. Clique nos botões para ver diferentes padrões de animação!

🎯 Conceito: Espaço vs Tempo

Sempre pense em velocidade como unidades por segundo, não por frame.
Exemplo: velocidade = 5 → o objeto anda 5 unidades a cada segundo, independente do FPS.

Isso é fundamental para criar jogos que se comportem da mesma forma em computadores lentos e rápidos.
