Controles com Teclado

⌨️ Como Funciona a Entrada do Teclado

No navegador, capturamos teclas com event listeners. O segredo para movimento suave é guardar quais teclas estão pressionadas agora, não reagir ao evento diretamente:

❌ Abordagem errada: mover o objeto dentro do evento keydown — movimento "empacotado"

✅ Abordagem certa: guardar estado das teclas num objeto, verificar no game loop a cada frame 
// Objeto para guardar quais teclas estão pressionadas
const teclas = {};

// Quando aperta: marca como true
window.addEventListener('keydown', (e) => {
  teclas[e.key] = true;
});

// Quando solta: marca como false
window.addEventListener('keyup', (e) => {
  teclas[e.key] = false;
});

🏃 Usando no Game Loop

const VELOCIDADE = 5; // unidades por segundo

function gameLoop() {
  requestAnimationFrame(gameLoop);

  const delta = clock.getDelta(); // tempo desde último frame

  // ← → ou A D: movimento lateral
  if (teclas['ArrowLeft']  || teclas['a']) {
    jogador.position.x -= VELOCIDADE * delta;
  }
  if (teclas['ArrowRight'] || teclas['d']) {
    jogador.position.x += VELOCIDADE * delta;
  }

  // ↑ ↓ ou W S: movimento de profundidade
  if (teclas['ArrowUp']   || teclas['w']) {
    jogador.position.z -= VELOCIDADE * delta;
  }
  if (teclas['ArrowDown'] || teclas['s']) {
    jogador.position.z += VELOCIDADE * delta;
  }

  renderer.render(cena, camera);
}
gameLoop();

📷 Câmera que Segue o Jogador

Em jogos com personagem, a câmera geralmente acompanha o jogador. A técnica mais simples é lerp (interpolação linear):

// Posição que a câmera QUER alcançar
const alvo = new THREE.Vector3(
  jogador.position.x,
  jogador.position.y + 8,  // acima do jogador
  jogador.position.z + 10  // atrás do jogador
);

// Lerp: move suavemente 10% do caminho por frame
// Isso cria o efeito de câmera "elástica"
camera.position.lerp(alvo, 0.1);
camera.lookAt(jogador.position);
