Colisões e Física Simples

🎯 O que é Detecção de Colisão?

Colisão é quando dois objetos "se tocam" no mundo do jogo. Detectar isso é fundamental para: dano, pontuação, paredes, pegando itens e mais.

Engines profissionais têm sistemas de física completos (PhysX, Bullet, Rapier). Para jogos simples, fazemos detecção manual com formas simplificadas.

⭕ AABB — Colisão por Caixa

AABB (Axis-Aligned Bounding Box) é o método mais simples: você envolve cada objeto em uma caixa invisível e verifica se as caixas se sobrepõem:

// Three.js tem Box3 exatamente pra isso!
const caixaA = new THREE.Box3().setFromObject(objetoA);
const caixaB = new THREE.Box3().setFromObject(objetoB);

if (caixaA.intersectsBox(caixaB)) {
  console.log('Colisão detectada!');
}

// IMPORTANTE: recalcular a cada frame,
// pois os objetos se movem!
function gameLoop() {
  requestAnimationFrame(gameLoop);

  // Atualiza as caixas com as posições atuais
  caixaA.setFromObject(objetoA);
  caixaB.setFromObject(objetoB);

  if (caixaA.intersectsBox(caixaB)) {
    // reagir à colisão
  }

  renderer.render(cena, camera);
}

⚪ Colisão por Distância (Esfera)

Para objetos redondos (personagem, bola, inimigos), colisão por distância é ainda mais simples e eficiente:

// Distância entre dois pontos no espaço 3D
const distancia = objetoA.position.distanceTo(objetoB.position);

// Se a distância for menor que a soma dos raios = colisão!
const raioA = 0.6;
const raioB = 0.8;

if (distancia < raioA + raioB) {
  console.log('Colisão de esferas!');
}
💡 Use colisão por caixa (AABB) para paredes, plataformas e objetos retangulares.
Use colisão por distância para personagens, projéteis e objetos circulares.
Combine as duas para jogos mais complexos!

🧱 Limites de Mapa

Para impedir que o jogador saia do mapa, simplesmente limite a posição:

// Definir os limites do mapa
const LIMITE = 9;

// Dentro do game loop, após mover o jogador:
jogador.position.x = Math.max(-LIMITE, Math.min(LIMITE, jogador.position.x));
jogador.position.z = Math.max(-LIMITE, Math.min(LIMITE, jogador.position.z));

// Forma alternativa usando clamp
jogador.position.clampScalar(-LIMITE, LIMITE);
