🏗️ Estrutura do Jogo

Um jogo completo precisa de:
Estado — pontos, vidas, nível
Entidades — jogador, inimigos, coletáveis
Sistema de colisão — para cada tipo
Spawner — cria inimigos ao longo do tempo
UI/HUD — exibe informações ao jogador
Estados de tela — menu, jogando, game over

💻 Spawner de Inimigos

// Criar um inimigo em posição aleatória
function spawnInimigo() {
  const geo = new THREE.BoxGeometry(1,1,1);
  const mat = new THREE.MeshStandardMaterial({
    color: '#ef4444'
  });
  const inimigo = new THREE.Mesh(geo, mat);

  // Aparecer nas bordas do mapa
  const lado = Math.floor(Math.random() * 4);
  if (lado === 0) inimigo.position.set( LIMITE, 0.5, rand());
  if (lado === 1) inimigo.position.set(-LIMITE, 0.5, rand());
  if (lado === 2) inimigo.position.set(rand(), 0.5,  LIMITE);
  if (lado === 3) inimigo.position.set(rand(), 0.5, -LIMITE);

  // Velocidade em direção ao jogador
  const dir = jogador.position
    .clone()
    .sub(inimigo.position)
    .normalize();
  inimigo._vel = dir.multiplyScalar(velocidade);

  cena.add(inimigo);
  inimigos.push(inimigo);
}

💡 Padrões Usados Neste Jogo

• Object Pool — reutilizar objetos ao invés de criar/destruir

• State Machine — "menu", "jogando", "game over"

• Delta time — velocidade consistente em qualquer FPS

• Lerp na câmera — movimento suave e elástico

• Spawn nas bordas — inimigos sempre aparecem longe do jogador
