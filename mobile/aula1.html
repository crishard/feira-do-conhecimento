📲 Desktop vs. Mobile

Antes de criar jogos mobile, entenda o que muda quando vai pro celular.

🖥️ vs 📱 — As Diferenças Principais

🖥️ Desktop
🖱️ Mouse com precisão de pixels
⌨️ Teclado com todas as teclas
📐 Tela grande e fixa
⚡ CPU/GPU mais poderosa
🔋 Sem problema de bateria
📡 Conexão estável (cabo)
📱 Mobile
👆 Toque com os dedos (grosseiros)
🕹️ Controles virtuais na tela
🔄 Tela pequena + rotação
🐢 Hardware mais limitado
🔋 Bateria é um recurso!
🌐 Wi-Fi, dados, pode cair

📐 Viewport — O Tamanho da Tela

A primeira coisa num jogo mobile é garantir que ele preenche a tela corretamente. A tag <meta viewport> é obrigatória:

HTML — No <head> de toda página mobile
<!-- SEM isso, o celular mostra a página em zoom de desktop -->
<meta name="viewport"
  content="width=device-width,  ← usa a largura real do celular
           initial-scale=1.0,   ← começa sem zoom
           user-scalable=no"  ← impede zoom acidental ao jogar
>

<!-- Canvas que preenche a tela toda -->
<style>
  canvas {
    width: 100vw;   /* 100% da largura da tela */
    height: 100vh;  /* 100% da altura da tela */
    display: block;
    touch-action: none; /* impede scroll acidental */
  }
</style>

👆 Mouse vs. Touch — O Código Muda

No desktop você usa mousemove. No mobile você usa touchmove. Mas pode suportar os dois ao mesmo tempo:

JavaScript — compatível com desktop e mobile
// Pegar a posição independente do dispositivo
function getPosicao(evento) {
  // Touch: evento.touches[0] = primeiro dedo
  if (evento.touches) {
    return {
      x: evento.touches[0].clientX,
      y: evento.touches[0].clientY
    };
  }
  // Mouse: direto no evento
  return { x: evento.clientX, y: evento.clientY };
}

// Registrar AMBOS os tipos de evento
canvas.addEventListener('mousemove', getPosicao);
canvas.addEventListener('touchmove', getPosicao);
💡 Regra de Ouro
Sempre desenvolva pensando em touch primeiro. Um jogo que funciona com o dedo geralmente também funciona com o mouse. O contrário NÃO é verdade!

📏 Tamanho dos Botões

O dedo humano ocupa entre 44px e 70px. Botões menores causam erros de toque. Essa é a regra da Apple e do Google para design mobile:

CSS — Tamanho mínimo de toque
/* Mínimo 44px × 44px (recomendação Apple/Google) */
.botao-jogo {
  min-width: 60px;
  min-height: 60px;
  border-radius: 50%;
  /* padding aumenta a área clicável sem mudar visual */
  padding: 12px;
  font-size: 1.5rem;
}
