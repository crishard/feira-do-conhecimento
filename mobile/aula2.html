👆 Touch Events

Como o navegador entrega os toques da tela para o seu código.

Os 3 Eventos Essenciais

touchstart
👇

Dedo toca a tela

touchmove
👉

Dedo desliza pela tela

touchend
☝️

Dedo levantou da tela

Como Usar na Prática

JavaScript
const canvas = document.getElementById('canvas');

// { passive: false } permite e.preventDefault()
// que bloqueia o scroll/zoom da página durante o jogo
canvas.addEventListener('touchstart', e => {
  e.preventDefault(); // impede scroll acidental!

  // e.touches = TODOS os dedos atualmente na tela
  // e.changedTouches = dedos que mudaram agora
  const toque = e.touches[0]; // primeiro dedo

  console.log(toque.clientX, toque.clientY);
}, { passive: false });

canvas.addEventListener('touchmove', e => {
  e.preventDefault();
  const toque = e.touches[0];
  // mover objeto para a posição do toque
  personagem.x = toque.clientX;
  personagem.y = toque.clientY;
}, { passive: false });

canvas.addEventListener('touchend', e => {
  // dedo foi levantado — parar movimento
  personagem.movendo = false;
});

Múltiplos Dedos (Multitouch)

O celular suporta vários dedos ao mesmo tempo. Cada toque tem um identifier único para você rastrear qual é qual:

JavaScript — rastreando cada dedo
const dedos = {}; // guarda posição de cada dedo

canvas.addEventListener('touchstart', e => {
  // Iterar sobre TODOS os dedos que tocaram agora
  Array.from(e.changedTouches).forEach(t => {
    dedos[t.identifier] = { x: t.clientX, y: t.clientY };
  });
});

canvas.addEventListener('touchend', e => {
  Array.from(e.changedTouches).forEach(t => {
    delete dedos[t.identifier]; // remove dedo levantado
  });
});

// No game loop, você usa:
Object.values(dedos).forEach(d => {
  // desenhar ou processar cada dedo ativo
});

O demo ao lado é uma tela de desenho. Use o dedo no celular ou o mouse no PC. Repara como múltiplos dedos criam traços independentes!
