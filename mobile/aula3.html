🕹️ Joystick Virtual

O controle mais comum nos jogos mobile — do PUBG ao Subway Surfers.

Como Funciona um Joystick

Um joystick virtual é basicamente uma âncora (centro) e um cabo (o ponto onde o dedo está). A direção e a força são calculadas pela distância e ângulo entre os dois:

JavaScript — lógica completa do joystick
const joy = {
  ativo: false,
  // Centro — onde o dedo tocou
  baseX: 0, baseY: 0,
  // Cabo — onde o dedo está agora
  caboX: 0, caboY: 0,
  // Direção normalizada (-1 a 1)
  dx: 0, dy: 0,
  raio: 60 // raio máximo do cabo
};

canvas.addEventListener('touchstart', (e) => {
  e.preventDefault();
  const t = e.touches[0];
  joy.ativo = true;
  joy.baseX = t.clientX; // âncora = onde tocou
  joy.baseY = t.clientY;
  joy.caboX = t.clientX;
  joy.caboY = t.clientY;
}, { passive: false });

canvas.addEventListener('touchmove', (e) => {
  e.preventDefault();
  const t = e.touches[0];

  // Distância do centro ao dedo
  const dx = t.clientX - joy.baseX;
  const dy = t.clientY - joy.baseY;
  const dist = Math.hypot(dx, dy);

  // Limitar o cabo ao raio máximo
  if (dist > joy.raio) {
    joy.caboX = joy.baseX + (dx / dist) * joy.raio;
    joy.caboY = joy.baseY + (dy / dist) * joy.raio;
  } else {
    joy.caboX = t.clientX;
    joy.caboY = t.clientY;
  }

  // Normalizar: valor entre -1 e 1
  joy.dx = (joy.caboX - joy.baseX) / joy.raio;
  joy.dy = (joy.caboY - joy.baseY) / joy.raio;
}, { passive: false });

canvas.addEventListener('touchend', () => {
  joy.ativo = false;
  joy.dx = 0; joy.dy = 0; // parar
});

Usando no Game Loop

JavaScript
const VELOCIDADE = 5;

function gameLoop() {
  requestAnimationFrame(gameLoop);

  // joy.dx e joy.dy vão de -1 a 1
  // Multiplicar por VELOCIDADE dá o movimento real
  jogador.x += joy.dx * VELOCIDADE;
  jogador.y += joy.dy * VELOCIDADE;

  desenhar();
}
💡 Joystick flutuante
No demo, o joystick aparece onde o dedo toca — não num canto fixo. Isso é chamado de "joystick dinâmico" e é mais confortável pois o jogador não precisa posicionar o dedo em lugar específico.
