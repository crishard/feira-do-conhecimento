🌀 Acelerômetro — Incline para Mover

Controle o jogo inclinando o celular — como nos jogos de labirinto e corrida!

O que é o Acelerômetro?

O celular tem um sensor chamado acelerômetro que detecta a inclinação e aceleração do aparelho nos 3 eixos:

X
Inclinação
esquerda/direita
Y
Inclinação
frente/trás
Z
Rotação
sobre si mesmo

A API DeviceOrientation

JavaScript
// Pedir permissão (necessário no iOS 13+)
async function ativarAcelerometro() {
  // iOS exige permissão explícita
  if (DeviceOrientationEvent.requestPermission) {
    const res = await DeviceOrientationEvent
      .requestPermission();
    if (res !== 'granted') return;
  }

  // Ouvir o evento de orientação
  window.addEventListener('deviceorientation', (e) => {
    // Valores em graus (-180 a 180)
    const incX = e.gamma; // esq/dir (-90 a 90)
    const incY = e.beta;  // cima/baixo (-180 a 180)

    // Normalizar para -1 a 1 (usando 45° como máximo)
    bola.ax = Math.max(-1, Math.min(1, incX / 45));
    bola.ay = Math.max(-1, Math.min(1, (incY - 30) / 45));
    // -30 porque o celular fica levemente inclinado
  });
}

Usando no Jogo

JavaScript — física da bola
// bola.ax e bola.ay = aceleração da inclinação
const GRAVIDADE = 0.5;

function gameLoop() {
  requestAnimationFrame(gameLoop);

  // Aceleração baseada na inclinação
  bola.vx += bola.ax * GRAVIDADE;
  bola.vy += bola.ay * GRAVIDADE;

  // Atrito (amortecimento)
  bola.vx *= 0.95;
  bola.vy *= 0.95;

  bola.x += bola.vx;
  bola.y += bola.vy;

  desenhar();
}
⚠️ iOS 13+ precisa de permissão
No iPhone, o acesso ao acelerômetro exige que o usuário clique num botão primeiro. O demo tem esse botão. No Android, funciona direto.

No demo ao lado, incline o celular para rolar a bola! No PC, mova o mouse para simular a inclinação.
