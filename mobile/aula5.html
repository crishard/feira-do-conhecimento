⚡ Performance e Vibração

Jogos mobile precisam ser leves. Veja os principais truques e a Vibration API.

📳 Vibração — Feedback Tátil

O celular pode vibrar quando o jogador toma dano, coleta um item ou ganha. É uma única linha de código:

JavaScript — Vibration API
// Vibrar por 100ms (um toque curto)
navigator.vibrate(100);

// Vibrar por 200ms (coleta item)
navigator.vibrate(200);

// Padrão: vibra 100ms, pausa 50ms, vibra 100ms (dano)
navigator.vibrate([100, 50, 100]);

// Padrão de vitória: três toques rápidos
navigator.vibrate([50, 30, 50, 30, 100]);

// Parar a vibração
navigator.vibrate(0);
⚠️ Safari / iOS
A Vibration API não funciona no Safari (iPhone). Funciona no Chrome Android e Firefox. Sempre verifique antes de usar!

if (navigator.vibrate) { navigator.vibrate(100); }

🚀 Truques de Performance

Celulares têm hardware mais limitado. Esses truques fazem seu jogo rodar a 60 FPS mesmo em aparelhos modestos:

1. Limpar só o necessário (evite fillRect no canvas inteiro)
// ❌ Lento: redesenha tudo
ctx.clearRect(0, 0, canvas.width, canvas.height);

// ✅ Rápido: limpa só onde os objetos estavam
ctx.clearRect(jogador.x - 20, jogador.y - 20, 40, 40);
2. Off-screen Canvas — pré-renderizar objetos estáticos
// Criar um canvas fora da tela para o cenário
const offscreen = document.createElement('canvas');
const octx = offscreen.getContext('2d');

// Desenhar o cenário UMA VEZ
desenharCenario(octx);

// No game loop, copiar o canvas pré-desenhado
// É MUITO mais rápido que redesenhar
ctx.drawImage(offscreen, 0, 0);
3. Object pooling — reutilizar objetos
// ❌ Lento: criar e destruir objetos
tiros.push(new Tiro(x, y)); // cria objeto
tiros.splice(i, 1);           // destrói — GC lento!

// ✅ Rápido: reutilizar objetos inativos
const pool = Array.from({ length: 50 },
  () => ({ x:0, y:0, ativo:false })
);

function atirar(x, y) {
  // Pegar um tiro inativo do pool
  const t = pool.find(t => !t.ativo);
  if (!t) return; // pool cheio
  t.x = x; t.y = y; t.ativo = true;
}
✅ Regra geral de performance mobile
Mantenha o game loop abaixo de 16ms por frame. Use ctx.drawImage ao invés de redesenhar primitivas. Evite criar objetos no loop. Reduza sombras e filtros CSS no canvas.
