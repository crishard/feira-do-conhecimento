🔺 Vértices, Arestas e Faces

Todo objeto 3D é uma ilusão matemática feita de pontos no espaço, linhas entre eles e triângulos que formam a superfície.

📦 Um Cubo por Dentro

Um cubo simples tem:

ComponenteQtdO que é
Vértices8Os 8 cantos do cubo
Arestas12As 12 bordas (4 por eixo)
Faces (quads)6As 6 faces planas
Triângulos12Cada quad = 2 triângulos

🤔 Por que Triângulos?

A GPU (placa de vídeo) só processa triângulos. Um quad (4 lados) é dividido em 2 triângulos internamente. Modeladores usam quads por conveniência, mas o hardware sempre vê triângulos.

💡 Mesh = malha
Em inglês, o conjunto de vértices + arestas + faces é chamado de mesh (malha). É o arquivo que você exporta do Blender para o jogo, por exemplo.

💻 No Código (Three.js)

JavaScript
// Um cubo é uma "geometria"
// Three.js já cria os vértices/faces pra você
const geometria = new THREE.BoxGeometry(1, 1, 1);

// Para ver a malha wireframe (arestas)
const matWire = new THREE.MeshBasicMaterial({
  wireframe: true,
  color: '#06b6d4'
});

// Inspecionar: quantos triângulos tem?
console.log(geometria.attributes.position.count / 3);
// Um cubo: 12 triângulos (2 por face × 6 faces)
