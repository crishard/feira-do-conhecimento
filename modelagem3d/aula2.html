🔄 Transformações

Toda operação em modelagem 3D se resume a três coisas: mover, girar e escalar. São as transformações fundamentais.

Mova os sliders para ver a matriz

💻 No Código

JavaScript — Three.js
// Mover (translação)
objeto.position.set(1, 0.5, -2);
objeto.position.x = 3; // ou um eixo só

// Rotacionar (em RADIANOS, não graus!)
objeto.rotation.y = Math.PI / 4; // 45°
// Para converter: graus * Math.PI / 180

// Escalar
objeto.scale.set(2, 0.5, 1); // esticado
objeto.scale.setScalar(2);    // uniforme
⚠️ Ordem das Transformações Importa!
Girar depois de mover ≠ mover depois de girar. A ordem é sempre: Escala → Rotação → Translação (SRT). Se mudar a ordem, o resultado muda!
