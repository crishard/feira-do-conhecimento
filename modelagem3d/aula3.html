💻 Exemplo de Código

JavaScript — construindo um boneco
// Cabeça = esfera
const cabGeo = new THREE.SphereGeometry(0.4, 16, 12);
const cab = new THREE.Mesh(cabGeo, matPele);
cab.position.y = 2.0;

// Corpo = cubo achatado
const corpGeo = new THREE.BoxGeometry(0.7, 0.9, 0.4);
const corp = new THREE.Mesh(corpGeo, matRoupa);
corp.position.y = 1.2;

// Perna = cilindro estreito
const pernaGeo = new THREE.CylinderGeometry(0.12, 0.1, 0.7, 8);
const pernaD = new THREE.Mesh(pernaGeo, matCalca);
pernaD.position.set(0.18, 0.4, 0);
💡 Dica Profissional
Programas como Blender, Maya e ZBrush funcionam exatamente assim. Você começa com um cubo ou cilindro e vai moldando. O segredo está em acertar as proporções primeiro, depois detalhar!
