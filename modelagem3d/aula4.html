🗺️ UV Mapping

Como aplicar uma imagem 2D numa superfície 3D sem distorção? É aí que entra o UV Mapping — um dos conceitos mais importantes de modelagem!

🤔 O Problema

Imagine um cubo. Ele tem 6 faces. Mas uma textura é uma imagem plana. Como você "cola" essa imagem no cubo sem distorcer?

📦 Analogia da embalagem
Pense numa caixa de sapato. Para fazer a caixa, você começa com um papelão plano (chamado "planificação") que é dobrado. O UV Map é exatamente isso: o modelo 3D "desdobrado" numa superfície plana onde você pode pintar.

🗺️ O que são U e V?

UV são as coordenadas na superfície 2D da textura — como X e Y, mas usamos U e V para não confundir com o espaço 3D. Cada vértice tem uma coordenada UV que diz qual pixel da textura pertence a ele.

JavaScript — acessando UVs
const geo = new THREE.BoxGeometry(1,1,1);

// Coordenadas UV de cada vértice
const uvs = geo.attributes.uv;
console.log(uvs.count); // 24 (4 vértices × 6 faces)

// Cada par (u, v) vai de 0.0 a 1.0
// (0,0) = canto inferior esquerdo da textura
// (1,1) = canto superior direito

// Aplicar textura
const loader = new THREE.TextureLoader();
const tex = loader.load('textura.png');
const mat = new THREE.MeshStandardMaterial({ map: tex });
