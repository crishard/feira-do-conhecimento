💻 No Código

JavaScript — MeshStandardMaterial (PBR)
const mat = new THREE.MeshStandardMaterial({
  color:     '#f97316',  // cor base
  roughness: 0.4,       // 0=espelho  1=fosco
  metalness: 0.8,       // 0=plástico 1=metal
  emissive:  '#ff4400',  // cor de brilho próprio
  emissiveIntensity: 0.5,

  // Com texturas (PBR completo):
  map:         texAlbedo,   // cor de base
  roughnessMap: texRough,   // rugosidade por região
  metalnessMap: texMetal,   // metal por região
  normalMap:    texNormal,  // detalhes sem geometria
});
💡 A regra do PBR
Na vida real, materiais não-metálicos têm metalness ≈ 0. Metais têm metalness ≈ 1. Roughness controla o quão "desgastado" está o objeto. Uma panela nova = metalness 1, roughness 0.1. Uma panela enferrujada = metalness 0.7, roughness 0.9.
