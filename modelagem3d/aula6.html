💡 Iluminação e Sombras

A iluminação muda tudo numa cena 3D. Você pode ter a melhor geometria e o melhor material, mas sem uma boa luz a cena fica morta. Vamos aprender os 4 tipos de luz.

🌐 AmbientLight — Luz de Preenchimento

Ilumina tudo igualmente, sem direção. É como a luz difusa do céu nublado. Sem ela, as partes não iluminadas ficam completamente pretas.

AmbientLight Sem sombra
0.40

☀️ DirectionalLight — Luz do Sol

Raios paralelos, como o sol. Tem direção fixa e é a principal fonte de sombras nas cenas. Uma cena realista geralmente tem 1 DirectionalLight como "sol".

DirectionalLight ☁ Sombra ON

💡 PointLight — Lâmpada

Irradia em todas as direções a partir de um ponto, como uma lâmpada ou vela. Tem alcance limitado (distance) e atenua com a distância.

PointLight Sem sombra
1.20
8.0

🔦 SpotLight — Holofote

Um cone de luz com direção definida, como um refletor de palco ou lanterna. O ângulo do cone (angle) e a suavidade das bordas (penumbra) são os parâmetros chave.

SpotLight ☁ Sombra ON

💻 No Código

JavaScript — Todos os tipos de luz
// Luz ambiente (preenche as sombras)
const amb = new THREE.AmbientLight('#ffffff', 0.4);
cena.add(amb);

// Luz direcional (sol) com sombra
const sol = new THREE.DirectionalLight('#fffbe6', 1.5);
sol.position.set(5, 8, 4);
sol.castShadow = true;
sol.shadow.mapSize.width  = 2048; // maior = mais nítido
sol.shadow.mapSize.height = 2048;
cena.add(sol);

// Lâmpada pontual
const lamp = new THREE.PointLight('#ff6030', 1.2, 8);
lamp.position.set(-2, 2, 2);
cena.add(lamp);

// Holofote com sombra
const spot = new THREE.SpotLight('#a0d4ff', 3);
spot.position.set(0, 6, 0);
spot.angle   = 0.4;  // largura do cone (rad)
spot.penumbra = 0.3; // suavidade da borda
spot.castShadow = true;
cena.add(spot);

// Objeto precisa de castShadow = true
// Piso precisa de receiveShadow = true
💡 Dica de artista
A receita clássica de iluminação 3D é a "regra dos 3 pontos": uma luz principal forte (key light), uma luz de preenchimento mais fraca no lado oposto (fill light), e uma luz de contorno atrás do objeto (rim light). Experimenta no estúdio ao lado!
⚠️ Performance
Sombras têm custo alto! Cada luz com castShadow = true renderiza a cena duas vezes. Para jogos, use no máximo 1–2 luzes com sombra, e prefira sombras pré-calculadas (baked shadows) quando possível.
