🧩 Os 3 Ingredientes de Qualquer Cena 3D

Cena — o "mundo"
Um objeto que guarda todos os outros objetos. Pensa como um array onde você dá .add() em tudo.
Câmera — os "olhos"
Define de onde e como você enxerga a cena. Tem posição (x, y, z) e campo de visão (FOV).
Renderer — o "pintor"
Pega a cena + câmera e desenha no canvas usando WebGL. É ele que faz o loop de animação.

💻 O Código Completo — Linha a Linha

primeira-cena.html JavaScript 
// ① CENA — o mundo que vai conter tudo
const cena = new THREE.Scene();
cena.background = new THREE.Color('#0a0a1a');

// ② CÂMERA — os olhos do jogador
// PerspectiveCamera(fov, aspecto, perto, longe)
const camera = new THREE.PerspectiveCamera(
  60,                // campo de visão (graus)
  largura / altura,  // proporção da tela
  0.1,               // distância mínima
  100                // distância máxima
);
camera.position.set(0, 2, 6); // posição no espaço
camera.lookAt(0, 0, 0);       // olha para a origem

// ③ RENDERER — o motor que desenha tudo
const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.setSize(largura, altura);
document.body.appendChild(renderer.domElement); // coloca na página

// ④ OBJETO — geometria + material = mesh
const geometria = new THREE.BoxGeometry(1, 1, 1); // forma
const material  = new THREE.MeshStandardMaterial({
  color: '#f97316'  // cor laranja
});
const cubo = new THREE.Mesh(geometria, material);
cena.add(cubo); // ← adiciona na cena (igual array.push)

// ⑤ LUZ — sem luz, tudo fica preto
const luz = new THREE.DirectionalLight('#ffffff', 1.5);
luz.position.set(5, 8, 5);
cena.add(luz);
cena.add(new THREE.AmbientLight('#ffffff', 0.4));

// ⑥ LOOP — igual um while(true), roda para sempre
function animar() {
  requestAnimationFrame(animar); // chama de novo no próximo frame
  cubo.rotation.y += 0.01;      // gira um pouco a cada frame
  renderer.render(cena, camera); // desenha tudo na tela
}
animar(); // inicia o loop
🔗 Conexão com o que você aprendeu
Variável → const cubo, const material
Objeto → { color: '#f97316' } é um objeto JS
Função → function animar() é a função de loop
Loop → requestAnimationFrame = o while(true) do 3D
Método → cena.add(cubo) = como array.push(item)
