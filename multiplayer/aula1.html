🧠 O que é Programar?

Antes de qualquer jogo, você precisa falar a língua do computador.

📦 Variáveis — As Caixas da Memória

Imagine que o computador tem muitas caixas onde guarda informações. Cada caixa tem um nome (pra você saber qual é qual) e um conteúdo (o valor guardado).

🎒 Analogia do dia a dia
Pensa numa mochila escolar. Você tem um compartimento chamado "lanche" onde coloca uma maçã. Mais tarde você troca a maçã por um biscoito. O compartimento continua sendo "lanche", mas o conteúdo mudou.

Em programação: nome da caixa = variável, o que tem dentro = valor.
JavaScript
// Criar uma variável (caixa) e colocar algo dentro
let nome = "Jogador 1";
let pontos = 0;
let estaVivo = true;

// Mudar o conteúdo da caixa
pontos = 10;        // agora pontos vale 10
pontos = pontos + 5; // agora pontos vale 15

Existem 3 tipos básicos de valor:

💬

Texto (String)

Sempre entre aspas. Ex: "olá", "Jogador 2"

🔢

Número (Number)

Sem aspas. Ex: 42, 3.14, -5

✅

Verdadeiro/Falso (Boolean)

Só dois valores: true ou false

📦

Objeto (Object)

Agrupa vários valores: { x: 10, y: 5 }

❓ Condicionais — Tomando Decisões

Programas precisam tomar decisões. "SE isso for verdade, ENTÃO faça aquilo. SENÃO, faça outra coisa."

🎮 Analogia de jogo
SE o jogador encostar no inimigo, ENTÃO tirar uma vida.
SE as vidas chegarem a zero, ENTÃO mostrar "Game Over".
SENÃO, continuar o jogo.
JavaScript
let vidas = 3;

if (vidas > 0) {
  // executa SE vidas for maior que 0
  console.log("Continue jogando!");
} else {
  // executa SE vidas NÃO for maior que 0
  console.log("Game Over!");
}

🔁 Loops — Repetindo Coisas

Um loop faz o computador repetir um bloco de código várias vezes sem você ter que escrever tudo de novo.

JavaScript
// Faz isso 5 vezes (i vai de 0 até 4)
for (let i = 0; i < 5; i++) {
  console.log("Rodada número " + i);
}
// Imprime: "Rodada número 0", "Rodada número 1"...

// Loop de jogo: roda enquanto o jogador estiver vivo
while (estaVivo) {
  // atualiza o jogo...
}

🍳 Funções — As Receitas do Código

Uma função é um bloco de código com um nome. Você escreve uma vez e chama quando precisar.

🍕 Analogia da receita
Receita "fazer pizza": pegar massa → colocar molho → colocar queijo → assar.
Você não re-escreve a receita toda vez que quer pizza. Você só diz "fazer pizza()".
JavaScript
// Definir a função (escrever a receita)
function moverJogador(x, y) {
  jogador.posicaoX = jogador.posicaoX + x;
  jogador.posicaoY = jogador.posicaoY + y;
  console.log("Jogador se moveu!");
}

// Chamar a função (usar a receita)
moverJogador(5, 0);   // move 5 pra direita
moverJogador(0, -3);  // move 3 pra cima

🎯 Resumo: Os 4 Pilares

📦

Variáveis

❓

Condicionais

Tomam decisões (se X, então Y)

🔁

Loops

Repetem ações (game loop, criar inimigos)

🍳

Funções

Agrupam código reutilizável (mover, atirar)
