🖼️ O Canvas — A Tela do Jogo

O canvas é um elemento HTML que funciona como uma tela em branco. Você controla cada pixel usando JavaScript.

HTML + JavaScript
<!-- No HTML: criar o canvas -->
<canvas id="jogo" width="800" height="500"></canvas>

// No JS: pegar o "pincel" para desenhar
const canvas = document.getElementById('jogo');
const ctx = canvas.getContext('2d'); // ctx = pincel

// Desenhar um retângulo
ctx.fillStyle = '#60a5fa'; // cor
ctx.fillRect(100, 100, 20, 80); // x, y, largura, altura

🔄 O Game Loop do Pong

A cada frame (60x por segundo), o jogo:

JavaScript
function gameLoop() {
  requestAnimationFrame(gameLoop); // chama de novo

  // 1. Apagar o frame anterior
  ctx.clearRect(0, 0, canvas.width, canvas.height);

  // 2. Mover a bola
  bola.x += bola.velX;
  bola.y += bola.velY;

  // 3. Verificar colisões (bater nas paredes)
  if (bola.y <= 0 || bola.y >= canvas.height) {
    bola.velY *= -1; // inverte direção
  }

  // 4. Ler teclado e mover raquetes
  if (teclas['w']) raqueteEsq.y -= 6;
  if (teclas['s']) raqueteEsq.y += 6;

  // 5. Desenhar tudo
  desenhar();
}
gameLoop();

// A bola colidiu com a raquete esquerda?
if (
  bola.x - bola.r <= raquete.x + raquete.w &&
  bola.y >= raquete.y &&
  bola.y <= raquete.y + raquete.h
