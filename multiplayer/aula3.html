🌐 Como a Internet Funciona?

Para criar jogos multiplayer online, você precisa entender como dados viajam pela rede.

📮 Analogia do Correio

📬 Pensa assim

Quando você manda uma mensagem no WhatsApp, ela sai do seu celular, passa por vários computadores na internet e chega no celular do seu amigo. Esses computadores no meio são os servidores. Você e seu amigo são os clientes.

🏗️ Cliente e Servidor

📱

Cliente

É você (o jogador). Pede informações e envia ações (mover, atirar).

🖥️

Servidor

Computador sempre ligado. Recebe tudo de todos os clientes e manda de volta.

🎮 Em um jogo multiplayer

Você aperta W → seu computador envia "jogador1 se moveu pra cima" ao servidor
→ o servidor atualiza a posição
→ o servidor envia a nova posição para todos os jogadores
→ seu amigo vê você se mover na tela dele

📡 O que é uma Mensagem (Pacote)?

Na internet, tudo que trafega são pacotes — pequenos blocos de dados. Um pacote tem:

Exemplo de pacote em JSON (formato muito usado em jogos)
{
  "tipo": "mover",
  "jogadorId": "player_42",
  "posicao": { "x": 150, "y": 320 },
  "timestamp": 1720000000123
}

⚡ Latência — O Atraso da Rede

O tempo que um pacote leva para ir do seu computador ao servidor e voltar chama-se latência (ou ping). É medido em milissegundos (ms):

PingQualidadeSensação no jogo
< 30ms🟢 ExcelentePraticamente instantâneo
30–80ms🟡 BomQuase imperceptível
80–150ms🟠 RazoávelDá pra jogar, mas dá pra sentir
> 150ms🔴 Ruim"Lag" — o jogo parece lento

📨 WebSockets — A Conexão de Jogos

A maioria dos sites usa HTTP (você pede, o servidor responde, acabou). Mas em jogos precisamos de uma conexão aberta o tempo todo. Para isso existe o WebSocket:

JavaScript — WebSocket básico
// Conectar ao servidor
const ws = new WebSocket('ws://servidor.com/jogo');

// Quando a conexão abrir
ws.onopen = () => {
  console.log('Conectado ao servidor!');
};

// Quando receber uma mensagem
ws.onmessage = (evento) => {
  const dados = JSON.parse(evento.data);
  atualizarJogo(dados);
};

// Enviar uma mensagem
ws.send(JSON.stringify({
  tipo: 'mover',
  x: jogador.x,
  y: jogador.y
}));

No nosso curso, ao invés de WebSockets com um servidor real, vamos usar o BroadcastChannel — que funciona da mesma forma, mas entre abas do mesmo navegador. O conceito é idêntico!
