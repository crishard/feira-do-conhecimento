📨 Mensagens Entre Janelas

Aprenda a fazer duas abas do navegador conversarem — o coração do multiplayer!

📡 O que é BroadcastChannel?

É uma API nativa do navegador que permite que abas, janelas e workers do mesmo site se comuniquem em tempo real, sem precisar de servidor.

🔗 Analogia do rádio
Pensa num walkie-talkie. Você sintoniza no canal 5 e outra pessoa no canal 5. Tudo que você falar, ela ouve — e vice-versa. O BroadcastChannel é exatamente isso, mas para abas do navegador.

Todos no mesmo canal recebem todas as mensagens.

💻 Criando um Canal

JavaScript — funciona em qualquer aba
// Criar/entrar no canal "meu-jogo"
// Qualquer aba que usar esse nome fica conectada
const canal = new BroadcastChannel('meu-jogo');

// ✉️ ENVIAR uma mensagem
canal.postMessage({
  tipo: 'chat',
  de: 'Jogador 1',
  texto: 'Olá! Vamos jogar?'
});

// 📬 RECEBER mensagens das outras abas
canal.onmessage = (evento) => {
  const msg = evento.data; // dados recebidos

  if (msg.tipo === 'chat') {
    console.log(msg.de + ': ' + msg.texto);
  }
};

📋 Como Funciona Passo a Passo

  • 1
    As duas abas abrem o mesmo arquivo HTML e criam um canal com o mesmo nome.
  • 2
    Quando a aba A faz canal.postMessage(dados), o navegador entrega para todas as outras abas do mesmo canal.
  • 3
    A aba B recebe via canal.onmessage = (evento) => { ... } e pode atualizar o jogo.
  • 4
    Isso acontece em milissegundos — rápido o suficiente para jogos em tempo real!

🆚 BroadcastChannel vs WebSocket

Os conceitos são os mesmos! A diferença é onde o "servidor" fica:

Comparação de código
// WebSocket (internet real)
const ws = new WebSocket('ws://meuservidor.com');
ws.send(JSON.stringify(dados));
ws.onmessage = (e) => processar(e.data);

// BroadcastChannel (entre abas)
const canal = new BroadcastChannel('meu-jogo');
canal.postMessage(dados);
canal.onmessage = (e) => processar(e.data);

// Percebeu? A ideia é IDÊNTICA!
💡 O que aprendemos aqui
A API BroadcastChannel tem os mesmos conceitos de WebSocket: você cria um canal, envia mensagens com postMessage e recebe com onmessage. Os padrões que você aprende aqui se aplicam direto à programação de servidores reais!
