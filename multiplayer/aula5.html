🔄 Estado Compartilhado

O maior desafio do multiplayer: como dois jogadores veem a mesma coisa?

❓ O Problema da Sincronização

Imagina que o Jogador 1 se move para a direita. O Jogador 2 precisa ver isso acontecer na tela dele. Mas como?

⚠️ Sem sincronização

Cada jogador só vê a si mesmo. Os mundos ficam diferentes. Cada um pensa que ganhou. Caos total! 😅

✅ Com sincronização

Sempre que algo muda, você envia um pacote com o novo estado. As outras abas recebem e atualizam. Todo mundo vê a mesma coisa!

📦 O que é "Estado do Jogo"?

O estado é tudo que você precisa saber para desenhar o jogo num determinado momento:

O estado do nosso jogo
// Estado completo do jogo
const estado = {
  jogadores: {
    'aba-abc123': { x: 100, y: 200, cor: '#60a5fa', nome: 'J1' },
    'aba-xyz456': { x: 400, y: 200, cor: '#f59e0b', nome: 'J2' },
  }
};

🔑 Regra de Ouro: "Dono do Estado"

Cada dado tem um dono. Só o dono pode modificá-lo. Os outros apenas lêem:

JavaScript
// MEU_ID = identificador desta aba
const canal = new BroadcastChannel('jogo');

function gameLoop() {
  requestAnimationFrame(gameLoop);

  // Só atualizo a minha posição (sou o dono)
  if (teclas['ArrowRight']) {
    estado.jogadores[MEU_ID].x += 3;
  }

  // Envio minha posição atualizada para todos
  canal.postMessage({
    tipo: 'posicao',
    id: MEU_ID,
    x: estado.jogadores[MEU_ID].x,
    y: estado.jogadores[MEU_ID].y,
  });

  // Desenho TODOS os jogadores (incluindo o outro)
  desenharTodos();
}

// Recebo a posição do outro jogador e atualizo
canal.onmessage = (e) => {
  if (e.data.tipo === 'posicao') {
    estado.jogadores[e.data.id].x = e.data.x;
    estado.jogadores[e.data.id].y = e.data.y;
  }
};
